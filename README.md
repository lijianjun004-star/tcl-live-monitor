# TCL 多平台直播监控系统

TCL 京东 / 淘宝天猫 / 抖音直播间状态监控与满播率考核。**与 TCL 智能练播房项目无关，不混库、不混部署。**

当前状态：仓库初始化（写入权限测试）。尚无生产代码、尚未部署、尚未开始任何真实监控或考勤。

核心口径：`LIVE` / 有证据的 `OFFLINE` / `UNKNOWN` 三态；`UNKNOWN` 不等于停播，不扣分。

## 目录

- `src/core/` 核心考核引擎（纯函数，无网络）：三态、迟到/中断判定、coverage、KPI、排班导入、实体直播间去重
- `config/platform-sources.json` 各平台状态源验收等级（当前均未验证 → 不产生正式成绩）
- `docs/可行性审计-2026-11-04.md` 本轮审计与证据表
- 测试：`npm test`（Node 22，无依赖）
