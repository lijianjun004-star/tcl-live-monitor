# TCL 多平台直播监控系统

TCL 京东 / 淘宝天猫 / 抖音直播间状态监控与满播率考核。**与 TCL 智能练播房项目无关，不混库、不混部署。**

当前状态：仓库初始化（写入权限测试）。尚无生产代码、尚未部署、尚未开始任何真实监控或考勤。

核心口径：`LIVE` / 有证据的 `OFFLINE` / `UNKNOWN` 三态；`UNKNOWN` 不等于停播，不扣分。

## R0.9 三平台店铺与直播间只读对账

对账、来源身份、状态过期、店铺关联和离线预览的说明参见 [`docs/R0.9-three-platform-registry.md`](docs/R0.9-three-platform-registry.md)。该模块不替换现有三平台状态探针，也不改变正式考核或定时任务。
