## 对话中已做的取舍

- 最初要求监控整页约 20 家店、支持视频墙、开播提醒和手机看板。淘宝搜索排序会变化，四个字「未找到店」不能推出店铺停播。用户最后指定六家核心店，并选择只在原标签页单次核对。
- 手机 + noVNC 解决了人工登录和看见同一页面的问题。用户手机连接国内网络时，远程 Chrome 仍在云主机上发请求。代码包保留搜索入口和复用说明，登录态只留在原工作区。
- 曾考虑 GitHub Actions、导入 Cookie、在新页面逐间打开和调整浏览器参数。实测成功路径依靠手动登录、正常有头 Chrome 和同页公开卡片，无需把这些历史试验作为接手步骤。
- 用户希望手机直接看结果、工作区省额度、交接包能交给其他助手独立复查。CloudBase 架构包含采集主机、云端存储接口、手机看板三个部分。开通静态托管不会自动启动采集 Chrome。
- 审计中提过页面选择器、20 店强校验、Chrome 进程争用、HTTP 触发器、跨域和 stale 提示。当前代码含 HTTP Web 函数及启动文件，基于本包源码核实问题是否仍存在。一次成功不能覆盖淘宝改版、下播分支或长期稳定性。
