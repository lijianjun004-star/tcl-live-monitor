## 成本与功能边界
- 每日最多一次新归档，而不是每5分钟上传90天大文件。
- GitHub 公共仓库的 Artifact 上限通常是90天，但实际还受仓库/组织配置和存储额度限制。**只有首次上传成功、检查到 expires_at 后，才可标记该日归档生效**。
- GitHub Actions 的 cron 是尽力调度，没有严格的每5分钟 SLA；错峰只减少部分风险，不证明100%触发。
- 90天归档保存的是**每日检查点**及其中滚动数据，不能为漏跑的日期补造巡检样本；也不是长期不可篡改数据库或实际90天运行验收。
- 没有京东可信 OFFLINE 数据源或公开账号完整映射；真人数字人识别、开播率/满播率仍未达到正式考核条件。
- 不修改 Pages，不发起购买，不采集 Cookie/Token，不直接写 GitHub repo 状态分支。
