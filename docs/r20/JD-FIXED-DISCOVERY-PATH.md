# 京东 R2.0｜固定直播间寻找与账号核验路径

状态：**实验性只读**，尚不能计算真实开播率。适用 TCL 6 个京东内部房间、公开 TCL／雷鸟品牌店铺和未知京东主播主页。

## 一、为什么调整路径

2026-11-10 正常浏览器已经核验：

1. [TCL官方旗舰店店铺资质页](https://mall.jd.com/shopLevel-721631.html) 正常可读，但未找到直播入口；[证据](https://agent.tinyfish.ai/runs/d1d93650-daa8-4c36-a057-c6c82dbf941e)。
2. [TCL冰箱洗衣机旗舰店首页](https://mall.jd.com/index-619517.html?from=pc) 正常可读，能够看到品类导航、商品、关注和客服，但**没有可见直播间链接**；[证据](https://agent.tinyfish.ai/runs/231a6403-8b51-4fba-b5d2-df9c3805405c)。客服链接中出现候选 `venderId=624085`，这只是待查商家标识，不能认定是直播账号身份。

因此**不再默认以京东店铺资质页面寻找直播间**，改走手机京东 APP 中的主播主页分享入口。公开教程的具体步骤参见 [阿里云直播巡检 Agent 文档](https://help.aliyun.com/zh/document_detail/3019653.html)；这只是可复现的操作路径，不能替代我们自己取得的目标店铺身份与 LIVE 证据。

## 二、七步固定路径

| 步骤 | 需要核实的内容 | 输出 | 失败规则 |
|---|---|---|---|
| 1. 选内部房间 | 从 `config/r20-jd-crosswalk-review.json` 读取内部 `ops_room_id`、`ops_shop_id`、品类 | 内部房间唯一键 | 与京东外部账号保持 PENDING |
| 2. 找真实京东店铺 | 仅检查京东消费者公开页面／已明确归属的商家资料 | 店铺名称及店铺来源 | 不能由同名 TCL 推断同号 |
| 3. 进入手机京东直播 | 在官方京东 App 的目标直播间点击店铺／主播昵称，进入主播主页 | 真实主播／商家公开主页 | 不使用平台隐藏 API 或绕过登录 |
| 4. 分享主播主页 | 主播主页右上角操作菜单 → 分享 → 复制链接 | 通常为京东分享短链或其他京东主页 URL | 复制来源必须明确，匿名短链不可直接认定身份 |
| 5. 正常浏览器打开一次 | 在普通浏览器打开分享链接，检查最终跳转是否留在可信京东域名及主播身份 | 可复访的**主播主页候选入口** | 异域重定向、验证码、登录墙立即 STOP |
| 6. 检查新鲜直播入口 | 仅当主页明确指向本账号的当次直播时进入一次；保留原始/最终链接及动态 `liveId` | 本次动态直播场次 + 观测时间 | 老直播 `liveId` 不是永久开播入口，无徽标不能推断 OFFLINE |
| 7. 对接排班与证据 | 复查外部主播身份↔内部 `ops_room_id`，再依据经审核排班计算 | 分母 `shift_id`、LIVE/UNKNOWN、5分钟窗口 | 身份/排班未确认则开播率保持 `null` |

**不能通过商城直播促销商品、店铺相似名称或后台历史房间数值自动建立外部账号对应关系。**

## 三、京东链接必须分类

下面只是公开格式样例，**不是 TCL/雷鸟直播地址**：

| URL 形态 | 可确认的信息 | 后续动作 |
|---|---|---|
| `https://3.cn/2ufAsT-f` | 京东短链，可能是主播主页，也可能是直播间；仅凭短链无法区分 | 正常浏览器只打开一次，核查最终归属 |
| `https://zhibo.jd.com/liveroom?liveId=39953002` | 单次直播 `liveId` 格式示例 | 此 ID **不是**稳定主播身份 |
| `https://lives.jd.com/#/39842812/live` | 某些第三方工具支持的历史直播哈希路由示例 | 原始格式只能成为场次候选，不能直接判当前 LIVE |
| `https://mall.jd.com/index-619517.html` | 商城店铺页面 | 不等于直播主页，不等于实时状态 |
| `venderId=624085` | 客服链接中观察到的候选商家标识 | 不等于直播主播 ID、直播场次 ID、内部 ops_room_id |

链接格式参考：

- [阿里云：如何从手机京东获取主播主页分享链接](https://help.aliyun.com/zh/document_detail/3019613.html)；
- [京东直播间与主播主页分享示例（第三方介绍）](https://ai9091.com/?p=1186)；
- [京东直播间每次开播可能产生不同直播 ID（第三方操作教程）](https://help.eqxiu.com/doc/3468/)。

不要直接复制第三方教程中的样例 ID 充当 TCL 账号。

## 四、当前已经具备的离线工具

`probes/r20/jd-share-intake.mjs` 和 `probes/r20/jd-share-intake-cli.mjs`：

```bash
# 一条命令解释手机京东分享短链。不会联网，不会打开跳转，不会给出未经核实的直播状态。
node probes/r20/jd-share-intake-cli.mjs --url "https://3.cn/2ufAsT-f"

# 按真实已知直播链接格式解析单次 liveId（仅格式示例，不是本项目已确认场次）
node probes/r20/jd-share-intake-cli.mjs --url "https://zhibo.jd.com/liveroom?liveId=39953002"

# 真实开播率准入审计（未导入真实排班时必须 null）
node probes/r20/jd-opening-rate-cli.mjs --as-of 2026-11-10T12:00:00Z
```

程序只解析本地字符串，不发送京东请求、不跟随短链跳转、不购买、不读取登录 Cookie；遇到非 HTTPS、仿冒域名、多个 URL、无效 liveId 会拒绝。即使获得独立人工审核的账号映射，仍需检验实际数据源和正式排班才能通过开播率门禁。

## 五、当前证据与下一门禁

- TCL 运营内部京东 6 房间两轮真实历史观察：5 LIVE、1 UNKNOWN，但外部主播/店铺身份仍未确认；证据 [Actions 42356978045](https://github.com/lijianjun004-star/tcl-live-monitor/actions/runs/42356978045)。
- 京东网页两家店铺可访问，均没有出现本店的可点击直播入口（仅证明该页面未展示入口）。
- TCL / FFALCON 公开店铺候选见 `config/r20-jd-public-store-candidates.json`，不允许自动回填六个内部房间。
- 正式排班来源尚未确认为这六个房间，每日开播率分母不可确定。
- **本轮依然没有确认任何 TCL 京东公开直播间的真实主播主页链接**。下一步只能依据正常手机京东分享链接或真实公开主播主页证据，逐个完成独立身份与场次核验。

保护边界：不改 main、不合并草稿 PR #31、不部署、不启用自动巡检、不得采集未经授权的数据或绕过平台访问限制。

## 六、官方 TCL 历史推广链接的新实证（仅作发现链路）

京东超级品牌日官方账号在 2026-05-23 的活动公告中提到 2026-05-24 TCL 京东自营旗舰店直播，并发布公开短链：https://t.cn/AX6U24yU。正常只读浏览器追踪该短链时，京东系统跳转到了 `plogin.m.jd.com` 登录页，`returnurl` 明确指向京东直播哈希路由：

```text
https://lives.jd.com/#/45583477
```

- 该 `45583477` 是**历史直播场次 URL 线索**，不是已核实的当前直播、当前主播账号或任何内部 `ops_room_id`。
- 因为京东要求登录，直播页内部的品牌/主播身份和直播内容 **BLOCKED**。没有绕过或重复访问。
- 为防泄露，公开仓库只保存去掉登录参数和追踪参数后的 `https://lives.jd.com/#/45583477`，不保留登录页完整查询串。
- 机器证据：`docs/r20/evidence/jd-2026-05-24-tcl-official-promo-historical-live-route.json`；
  正常浏览器：[只读核验记录](https://agent.tinyfish.ai/runs/f5a4adbb-e385-45db-a9ea-1f6dcab1dc77)；
  [京东官方活动公告（微博同步页面）](https://www.sina.cn/news/detail/5301676329930260.html)。
- 对应离线模块 `probes/r20/jd-login-redirect-evidence.mjs`，只会从允许的京东登录 `returnurl` 提取历史场次候选，不会登录、刷新或将此历史线索升级为当前 LIVE。
- 最新的 `probes/r20/jd-mobile-share-cli.mjs` 可以通过 **stdin** 处理手机京东分享消息，仅输出脱敏来源摘要；真实分享短链可能含追踪参数，未经脱敏不得提交到公开 GitHub。
