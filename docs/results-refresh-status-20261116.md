# 结果站刷新状态与关联

任务：GH-20261116-RESULTS-01。总负责人 ChatGPT，执行者为本会话 Codex。
来源：main `15ded060f7d47a3d5a44ebcf041c1e957bff21e8`；额外模型请求 0；不新增服务或额度。

保留原采集完成触发、转义的抖音工作流名称、main 限制及原凭据回退。
helper 使用可信 main 文件；PR 只做离线验证，不接触凭据或真实采集。

刷新状态分开：

- NOT_DISPATCHED：凭据缺失、格式不符或 401/403；保留原先非致命退出规则。
- DISPATCHED：GitHub 返回 204，只证明接受发布请求，不证明发布完成。
- FAILED：请求异常或其他 HTTP 状态；一次请求，连接 10 秒/总计 45 秒，无自动重试。

状态写入结构化日志、步骤输出和 Job Summary，不输出凭据或 HTTP 响应体。
可选数字 collector_run_id / dispatcher_run_id 传给结果站，关联来源采集和派发运行。
结果站 publish.yml 的 PUBLISHED/NOT_PUBLISHED 才说明该次发布结果，
数据截至时间仍须查看各平台快照；收到触发不代表已经有新数据。

本轮不改采集脚本、登记表、冷却逻辑、采集 cron 或权限。不触发真实源测试。
离线测试使用本地 curl 替身，覆盖缺凭据、鉴权拒绝、204、429、超时和关联输入；
全仓现有测试一并执行。合成测试不构成真实派发或上线证据。

部署顺序：先合并 tcl-live-results 的可选输入，再合并此 PR。
回滚顺序：先回滚此 PR，再回滚结果站输入；旧无输入派发兼容结果站新版本。
