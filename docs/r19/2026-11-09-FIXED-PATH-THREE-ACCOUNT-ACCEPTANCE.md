## 业务归属冲突处理

TCL空调总部官方直播间主页可见认证主体为**内蒙古梯西爱迩销售有限公司**。该实体与“TCL总部”昵称不同，不能自动认定为 TCL 总部法律实体直营，也不能反过来推断其没有 TCL 授权。

本期规则：

- 账号真实性：用抖音号与 `secUid` 判断，身份核实通过。
- 直播状态：因直播页出现登录弹窗，`UNKNOWN / AUTH_REQUIRED`。
- 经营归属：`PENDING`，不纳入自动考核。
- 无法确认直播时不通过间接计算推定开播时刻或停播。

## 证据数据的后续复用

新增 `probes/r19/audit-fixed-path-evidence.mjs`，校验新的 JSON 证据与 14 个账号台账精确一致：

1. 账号 `key`、显示抖音号、`secUid`、主页链接不能交叉冒用。
2. 原始直播链接必须是 `live.douyin.com` 同一账号路由，`room_id` 必须是动态会话编号而非路由号。
3. 最终直播页移除查询参数时，只允许落在完全一致的直播路由，不能跳到另一个直播间。
4. 只有主页身份和当次直播标记、直播间身份及可见直播 UI 都通过，才记录**历史某次 LIVE 页面观测**。
5. 登录拦截不能记录 LIVE；未建立真实 OFFLINE 规则之前禁止写入 OFFLINE。
6. 所有过去的页面数据在当下状态中始终视为 `UNKNOWN`，不得复用成现在 LIVE。
7. 经第三方运营/认证主体存疑的账号单独保留经营归属 `PENDING`。

配套测试：`tests/r19-fixed-path-evidence.test.mjs`，只用离线数据做回归，不向抖音发请求。
