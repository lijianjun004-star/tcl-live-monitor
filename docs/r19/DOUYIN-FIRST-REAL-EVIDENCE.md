## 本轮结果

日期（北京时间）：2026-11-09。浏览器实际观测没有可靠的秒级来源时间，因此仅记录日期，不伪造具体分钟。

- 从仓库 main 的 \`config/probe-targets.json\` 继承 12 个抖音账号；
- 正常公开浏览器核实了其中 9 个账号主页身份；
- 另外发现 **2 个不在旧名单中的独立 FFALCON 旗舰店账号**，通过作者主页链接和抖音号核实；
- 全部 14 个账号的 secUid 唯一；
- 8 个账号主页当次出现“直播中”入口，并能获得直播路由和动态 webcast \`room_id\`；
- 3 个账号已核对身份，但没有出现本账号的直播标识，状态仍为 UNKNOWN；
- 3 个旧账号本轮未访问，保持 NOT_CHECKED；
- 另有 4 条无独立 secUid 的线索仅作候选，不纳入监控数。

**当前没有二次确认 8 个直播间内部的主播名称和直播页面状态。因此 8 条应称为 PROFILE_LIVE_BADGE，不代表已完成直播间双页验收，也不证明真实开播时刻。**

## 账号串联规则

\`\`\`text
稳定 secUid + 显示抖音号（身份核验）
       ↓
官方账号主页的直播中标记 + live.douyin.com 路由
       ↓
当次公开页面动态 room_id（场次候选）
       ↓
直播页面二次核验（未完成门禁）
       ↓
业务层 LIVE / OFFLINE / UNKNOWN
       ↓
R1.8 DurableStore + hourlySlot + manual check
\`\`\`

- 账号通过 secUid 去重，昵称变化不新建账号。
- 两个新雷鸟账号与旧雷鸟电视旗舰店 secUid 不同，不合并。
- RayNeo AR 和第三方渠道默认不纳入 TCL 大家电主巡检。
- 企业认证主体并不一定等于 TCL 总部法律主体。需要单独确认业务归属，**现阶段所有账号仅监控，不执行考核**。
- 直播身份二次核验尚未完成时，R1.8 标准化 LIVE 仍应为 UNKNOWN，另记录 PROFILE_LIVE_BADGE 观测事实。
- 仅当重新打开页面产生新证据时才更新当前状态；历史 LIVE 不可当成当前 LIVE。
- 无徽标、登录墙、验证码、超时、限流均不得判为 OFFLINE。

## 当前落地功能

1. 新增 \`config/r19-douyin-tcl-ffalcon-registry.json\`：14 个账号，8 条实际主页直播徽标证据，4 条待核身份线索。
2. \`probes/r19/douyin-first.mjs\`：身份/场次路由去重验证、每小时/手动巡检计划、有限期页面证据初筛。
3. \`probes/r19/cli.mjs\`：生成独立巡检计划并允许对已经取得的正常公开页快照做验证；默认零平台访问。
4. \`tests/r19-douyin-roster.test.mjs\`：覆盖身份、不同雷鸟账号、幂等、无直播标识不判停播、限流降级、过期证据拒绝。
5. GitHub Actions 仅做离线测试，不执行平台访问或正式巡检。

### 运行示例

\`\`\`bash
node --test tests/*.test.mjs
node probes/r19/cli.mjs --mode hourly --at 2026-11-09T06:04:00Z --out r19-plan.json
node probes/r19/cli.mjs --mode manual --key tcl-douyin-flagship --request-id local-001 --out r19-manual.json
\`\`\`

以上是**计划生成器**，不是自动浏览器实时监控。下一步需接入合法正常页面实际抓取模块，并在独立测试环境至少通过一次跨整点巡检及一次真实直播间二次身份核验，才能讨论自动部署。
