## 实现和反推修复

- 保留三平台内部 ID 命名空间，不将京东店铺 ID、场次 ID、抖音 secUid 和房间 ID 混用。
- 嵌套分页、冲突 total、无总数、重复 ID、无效 ID 都不能声明目录完整；不安全整数拒绝，数字 ID 前导零统一后去重；拒绝对象原型属性冒充平台。
- 对账审计逐项核对公开账号身份、配置键、平台、稳定 ID 和资格，不能用相同总数掩盖身份替换。已导入内部记录仍明确列出外部账号映射缺口；孤立店铺单列。
- 投影拒绝重复目录键；过期或未来记录不能覆盖当前状态；最新 UNKNOWN 不回退到旧 LIVE，新的有效样本可恢复。
- 公开 LIVE 必须携带生产探针的身份佐证；抖音要求主页和房间身份及实际检查的房间一致；京东 LIVE 要求采集代理存活佐证。
- 抖音 OFFLINE 投影读取生产报告级校准标志，缺少任一必要证据保持 UNKNOWN。天猫规则未校准时仍 UNKNOWN。全部投影显式 `formalScoringEnabled=false`。
- 天猫空值/空字符串/布尔状态不能转换成停播；同次详情响应 LIVE/OFFLINE 冲突保持 UNKNOWN。抖音校准后仍要求匹配房间身份才能确认停播。
- 离线页更新内部待映射计数，CSV 导出遵守当前筛选，保留脚本转义、文本渲染和 CSV 公式防护。
