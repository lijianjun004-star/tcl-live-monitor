## 2. 原因（有证据）

- 本次放行的核心 CDN 资源数（script 192 个，stylesheet 40 个）和 R3.23 运行完全相同，说明直播间页面**一个核心 CDN 资源都没用**。
- 与 R3.23 运行相比，多被拦的就是直播间页面的资源：8 个脚本和 14 个样式表，全部来自两个核心 CDN 以外的主机。
- 所以直播间页面的程序没有运行：拿不到标题和描述，DOM 里也没有指向主播主页的链接（私有记录：`ownerLinks = []`）。
- 私有结构诊断（只有标签链）：主页上的"直播中"链接位于 `div[user-detail]` 之内，不在 `user-info`、`profile-header`、`author-info` 中。在确认 `user-detail` 里不会出现别人的直播链接之前，**不**把它加入主播信息容器的判定范围，暂时继续用登记直播间做兜底。
