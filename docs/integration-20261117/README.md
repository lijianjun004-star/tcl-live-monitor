## 产品语义

1. 账号、店铺、实体房、直播场次分别标识。去重按 platform+accountId，重复绑定/观测不自动选优或合并。显示名称、数字相同、房间序号不能建立公开身份。
2. 每个登记账号保留一行。缺样、来源失败、登录异常、旧数据、新心跳配旧观测都不等于停播。来源/登录/新鲜度/心跳轴分别呈现。
3. effectiveObservedAt 只表示有证据的观测时刻，不是采集尝试、上传、评价时刻或真实开播时间。审定起止区间由调用者明确给定，不擅自设定生产有效期或频率。
4. OFFLINE 需独立、明确、审定的负证据；原型布尔审定仅为输入声明。没有正式开播率/满播率、真实时长或考核启用。
5. 恢复失败不能用更早 latest-success 掩盖。天猫缺失/损坏清单、失败运行停止标记和恢复链不明均持久阻塞；人工复核按确切文件摘要/运行/期限绑定，不生成任何真实批准。
6. 时钟 Worker 默认不派发；离线账本先预留、接受后仍待反馈、超时结果未知、来源失败退避到期仍待复核。状态摘要链用于意外损坏检查，不是签名或分布式锁。
