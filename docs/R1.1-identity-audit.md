## 四层身份与部分成功
1. 公开店铺（店铺名＋公开店铺入口）：可独立确认 `STORE_ONLY`，但不得当作直播间。
2. 稳定账号（抖音 `secUid` 或天猫 `accountId`）：已有来源证据标为 `ACCOUNT_ONLY`。
3. 直播场次（抖音 `roomId`、淘宝直播 `roomNum`）：只有对应账号与房间页历史交叉核验状态为 `VERIFIED` / `ROOM_ID_ROTATED_VERIFIED` 才标记历史公开直播间身份闭环；需持续重新验。
4. 京东内部运营房间：只列为 `OPS_INTERNAL_ONLY`；不能把运营 roomId / shop_id / SKU 当公开直播 `liveId`。

单店核验互相隔离。一店失败或访问受阻不使其他店铺失败。保留反证、别名、多来源及缺失项。LIVE / OFFLINE / UNKNOWN 均有观察时间；过期观察绝不能作为当前状态。
所有新增候选、历史五个考核标记均 `scoringEligible=false`（严格布尔），主体归属与长期稳定性均未验收。
不保存个人登录凭据、Cookie、token。不绕过登录／验证码／风控或此前 Work 淘宝浏览器安全策略。
