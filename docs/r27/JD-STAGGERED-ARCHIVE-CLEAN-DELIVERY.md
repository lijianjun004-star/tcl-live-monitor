## 特别重要的限制

- 90 天是 GitHub Artifact 的单份保留**配置上限**，而不是完成了真实连续90天的运行或数据可靠性承诺；账户/组织级更短保留策略仍会覆盖。
- 每日归档是一个**时点快照**，不等于整个自然日逐分钟完整记录。每次快照中 `checks` 最多7天，`events` 最多90天；若无人值守调度漏执行，历史有缺口不能自行补回。
- 公开 GitHub 仓库的标准托管 Runner 通常免费，但存储配额仍受账户与平台政策限制；不得保证永久免费无限容量。
- `schedule` 真正触发、90天连续存储、独立 OFFLINE 证据和正式开播率需要继续单独实测。
